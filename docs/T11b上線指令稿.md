### A-2 建 `.env`

> 🖥️ **在哪執行:** Cats VM(ssh 進去)· 工作目錄 `/opt/cats-inbox`
> 📄 **編輯哪個檔:** `/opt/cats-inbox/.env`

以 repo 的 `.env.example` 為底,**三個沒有預設值的必填**:

| 變數 | 從哪裡來 |
|---|---|
| `POSTGRES_PASSWORD` | 自行產生(`openssl rand -base64 24`)|
| `INBOX_OIDC_CLIENT_SECRET` | 🔴 **VM 上的** `idp/.env.keycloak.cats-inbox`(600)|
| `INBOX_SESSION_SECRET` | 自行產生(`openssl rand -base64 32`)|

🔴 **client secret 只在那台機器上合併,不要複製出那台機器。**

⚠ **`INBOX_OIDC_INTERNAL_BASE` 必須逐字等於交付檔裡那一行**(`http://keycloak:8080/auth`,
**不含 `/realms/…`**)。填錯會組出 `/realms/sporton/realms/sporton` → discovery 404,
而**離線測試全綠,只在第一個真人登入時出現**(T04 記過)。

## B 段:容器起來 + migration(不需要低峰窗口)

🔴 **為什麼這一段安全**:gateway 上**還沒有 `/inbox/` 路由**(T11a 的設定整段是註解),

### B-1 起容器

> 🖥️ **在哪執行:** Cats VM(ssh 進去)· 工作目錄 `/opt/cats-inbox`

```bash

sudo docker network disconnect cats-edge cats-inbox-api 2>/dev/null || true

```

### B-2 🔴 驗網路隔離線(A.3 紅線)

```bash

sudo docker inspect cats-inbox-api -f '{{range $k,$v := .NetworkSettings.Networks}}{{$k}} {{end}}'
# 期望:inbox-internal 與 cats-edge 兩個

# 🔴 DB 不得在 cats-edge、不得對主機發布 port
sudo docker inspect cats-inbox-pg -f '{{range $k,$v := .NetworkSettings.Networks}}{{$k}} {{end}}'
# 期望:只有 inbox-internal
```

### B-3 備份後跑 migration(🔴 顯式的一步,不在啟動時自動跑)

```bash

  > ~/inbox-before-$(date +%Y%m%d-%H%M).sql
sudo docker exec cats-inbox-api alembic upgrade head
sudo docker exec cats-inbox-api alembic current
sudo docker exec cats-inbox-pg psql -U cats_inbox -d cats_inbox -c '\dt'
```

### B-4 🔴 補上 PG 15 的 up→down→up 演練(開發機只有 16.13)

```bash

```

⚠ 現在庫是空的,所以 `downgrade base` 沒有資料風險。**上線之後不得再這樣做。**

### B-6 順手把 T03/T04/T06 留下的三項真人驗證做掉

```bash

    "redirect_uri": os.environ["INBOX_PUBLIC_BASE_URL"].rstrip("/") + "/inbox/oidc/callback/",

except urllib.error.HTTPError as e:

    print(e.code, body.get("error"))
```

### D-1 拉到正確的分支,並**驗 commit 對得上**


⚠ **`git log` 那一行不是形式**:portal 2026-08-03 的事故就是 `git pull` 回

### D-2 套用(一次性容器先驗 → 備份 → 套用 → 驗五條路由,不通自動回滾)

```bash

```

🔴 **`--check` 沒過就停手。** 它用一次性容器跑 `nginx -t`,**不碰正在服務的 gateway** ——
`host not found in upstream "cats-inbox-api"` 表示 B 段的容器沒起來或不在 `cats-edge`。
